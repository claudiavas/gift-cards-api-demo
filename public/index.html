🎁 Gift Cards API

API REST que automatiza un programa de recompensas por referidos: genera tarjetas regalo de Amazon, las encripta con AES-256-GCM, las entrega por email y deja una pista de auditoría inmutable.

Node.js + Express Amazon Incentives API AES-256-GCM BigQuery SendGrid Cloud Logging Docker + CI
🧪 Modo demostración: las llamadas que haces aquí son peticiones HTTP reales a esta API. Amazon, BigQuery y SendGrid están simulados — los códigos son ficticios y ningún email se envía de verdad.

Decisiones de seguridad

    
El diseño parte de una premisa: ni la base de datos, ni los logs, ni el propio desarrollador deben poder ver un código de tarjeta.

    

      
🔐 Encriptación inmediata
El código se encripta con AES-256-GCM en el instante en que Amazon lo devuelve. Solo se desencripta en memoria, justo antes de componer el email, y la variable se anula después.

      
🧹 Sanitización de logs
Un middleware intercepta todo lo que va a los logs y redacta códigos de tarjeta, claves AWS, tokens de API y emails mediante patrones regex.

      
🔁 Idempotencia
Un creationRequestId único y un constraint sobre el referido garantizan que un reintento del scheduler nunca genere (ni pague) dos tarjetas.

      
📋 Auditoría independiente
El log de accesos es inmutable y el rol de auditor es de solo lectura: la empresa puede verificar qué pasó con cada código sin depender del desarrollador.

      
🚦 Rate limiting
Límites por API key e IP, y reglas específicas de reenvío: máximo 1 por hora, 3 al día y 5 en total por tarjeta.

      
🛡️ Manejo de errores de Amazon
Los códigos de error (F300 fondos, F400 temporal…) se traducen a estrategias distintas: reintento con backoff exponencial, alerta al CRM o fallo controlado.
